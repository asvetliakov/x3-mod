### Performance
- **Collision** (the former 24 fps area): SSE2 box test + no-contact memo are launcher
  defaults: 65 fps standing, 45 fps moving. Moving case = player ship vs the station's OBB
  tree, ~10^5 node visits/frame at the fixture's per-visit floor. Closed with evidence:
  whole-descent SSE2 (no gain under FEX reduced precision), conservative advancement
  (gap too small deep in the tree), front tracking (1.13×), cache misses (not the cause).
  Do not cap or stride the engine's tests. [sector-collide.md](reverse-engineering/sector-collide.md) §12–14.9.
- **Small-parts cull** default 2 px scope all: busy station 884 → ~480 draws, ~50 fps.
- **Per-draw:** lever 1 merged and flown; lever 3 (`--motion-rt-mode lazy`) flown in run 47 B:
  set_rt 1560 → 3 per frame but native draw time rose by the same amount (wined3d defers the
  cost), no FPS gain: stays an option. `view_submit` engine arithmetic is < 0.65 ms
  ([view-submit-hot-path.md](reverse-engineering/view-submit-hot-path.md)); the sampling
  profiler is blind under FEX; `--submit-phases` (stamps for the sort, cache walk,
  SetTechnique/End, per-draw block, matrix inversions) is merged and unflown: one busy-station
  flight decides whether any candidate R1–R8 is worth a patch. Expect ≤ 1.5 ms items from
  here on.

### TAA / shimmer (goal 11)
- **Lattice crawl: root cause found.** The user's screen recording matches the presented
  frames 1:1; what crawls is the plant's near-edge-on ARM (not the face-on panels every
  earlier analysis measured): pixels toggle geometry/sky across the 8 jitter phases (p99
  151 codes, 7.3 Hz, a travelling temporal moiré) and the 3×3 variance clip discards the
  history. Fix merged, unflown: `--taa-thin-region W[,RELAX[,LO,HI]]` (fragmented-structure
  mask, clip off + phase-balanced history through the age target, speed gate on the fastest
  pixel within 8 px): arm 16.9 → 2.3 codes rms in replay on run175, 0 px > 40 codes; slow
  drift leaves trails of p99 6–21 codes (the trade to judge in flight).
  [taa-lattice-crawl.md](architecture/taa-lattice-crawl.md) §12–13.1, second opinions
  `taa-lattice-crawl-second-opinion.md`, `taa-lattice-crawl-blind-review.md`.
  `--taa-line-filter` stays an option (does not reach the arm).
- **Distant station lines:** `--taa-far-stabiliser 0.985` (weight only) accepted by the user
  in run 47 C with the default speed gate 0.03–0.25 (narrower gate judged worse); what still
  shimmers there is the light-map windows → `--light-map-far-fade P0,P1[,G]` merged, unflown
  (first flight `40,110`). Intended defaults after one confirming flight:
  far stabiliser 0.985 + thin region 0.97 + light-map far fade.
- Rejected with evidence: adaptive weight (user), global current filter (blur), sharpen
  exclusion, thin clip, MSAA, SSAA (user), jitter resequencing, luminance clamp, node fade
  band, more/other jitter samples, sharper history resampling. Mip bias −0.5 stays.

### Shadows
- **Argon Prime had sun shadows off in 96 % of frames** (run174): the `adeffects`
  advertisement signs are an opaque vs_2_0/ps_2_0 pair the SM3-only route cannot register
  and the lane vetoed the frame. Fixed and merged, unflown: the unknown depth writer is
  re-drawn once with a stamp shader (share −1 on the pixels it won), only that object is
  unshadowed; fails closed. Flight check: `sun_shadow_apply_frame applied=1` on ~all frames,
  `stamped` = number of adeffects zwrite draws, signs cleanly lit (no shadow speckle).
  [directional-shadows.md](verification/directional-shadows.md) "Run 174".
- **Shader coverage:** `tools/analysis/shader_coverage_offline.py` enumerates all 817
  shipped pairs offline (effects are precompiled): the SM3 tree is fully registered (171/180;
  the rest are bloom post passes); SM2/SM1 trees are unregistered (only reachable at lower
  shader quality, plus `adeffects`). Second `z_only` prepass pair registered.
  [shader-coverage-offline.md](verification/shader-coverage-offline.md),
  [shader-coverage-census.md](verification/shader-coverage-census.md).
