## Legend

* **Size**: size = the smallest tier holding at least 10 % of the tier-class TShips rows that can mount a laser firing the bullet (fewer is treated as an outlier row): small M5/M4/M3; medium M6/M8/TS/TS_PIRATE/TP/TM; big M7/MISSILE_FRIGATE/M2/M1/M0/TL/DRONECARRIER; other = only non-tier classes (drones, satellites, UFO, Kha'ak cluster, ...) mount it; unmounted = no ship mask admits its laser subtype or no TLaser row fires it; the TShips rows SS_SH_TURRET, SS_SH_TLS, SS_SH_TL_P, SS_SH_TL_P2 (a static turret and station-like rows with catch-all masks) are left out.
* **Used by**: ship classes (TShips col 52) with the number of TShips rows whose main-cockpit mask (col 18) or a turret cockpit mask (TCockpits col 8 of the indices in TShips cols 31..41) has the bit of the laser's SG_LASER_* subtype (TLaser col 5; values from the EXE table 0x00552888). The bit-to-subtype reading is inferred; lasers sharing a subtype (SPECIAL, KYON, UNKNOWN1/2) share their used-by.
* **Name**: TLaser col 6 on text page 17 (highest page version first, `{page,id}` expanded, `(...)` comments dropped). **Rate**: 60000 / TLaser col 7 (refire interval ms).
* **Speed** = TBullets col 11 / 500 m/s; **range** = col 10 (ms) x col 11 / 1000 / 500 m; **damage** = col 7 shield / col 22 hull per shot; **light** = cols 13-15 as hex.
* **Style** (classifier `verification/results/weapon-effects-census/classify_preview.py`): `beam` flag 0x2 or 0x4; `wave` flag 0x8 (fixed length); `tracer` body LOD-0 z/xy >= 4.0; `slug` 1.5 <= z/xy < 4.0, or no body extents; `orb` z/xy < 1.5; `+burst` the bullet ends in its own death explosion (0x100) or fragments (0x1000).
* **Flags** (TBullets col 12): `unknown_0x1` 0x1: set in rows, no EXE test found; `beam_gun_tied` 0x2: beam kind A, tied to the gun and refreshed each fire tick; `beam_kind_b` 0x4: beam kind B, length col 18; `beam_fixed_length` 0x8: fixed length col 18; `unknown_0x10` 0x10: set in rows, no EXE test found; `hull_damage_through_shields` 0x20: hull damage even when the shields absorbed; `ammunition` 0x40: uses ammunition; `repair` 0x80: repair, hull damage negated; `area_flak` 0x100: area/flak, explodes on death with the impact row (col 20), speed zeroed; `on_hit_slow` 0x200: on hit slows the victim (cols 28/29); `on_hit_energy_drain` 0x400: on hit drains victim energy (col 30); `on_hit_col31_32` 0x800: on-hit victim effect from cols 31/32; `fragments` 0x1000: spawns fragment bullets at lifetime expiry (cols 33/34); `continuous_beam` 0x2000: continuous beam with its own end time (col 27).
* **Effects**: Effects row ids of muzzle (col 21), flight (col 19), impact (col 20) and, with 0x100, death (= impact).
