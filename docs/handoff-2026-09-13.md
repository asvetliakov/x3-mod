## 1. What the project is

A D3D9 proxy (`d3d9.dll`, MinGW i686, private-vtable wrapper) that modernises
the rendering of *X3: Albion Prelude* (32-bit, static MSVC CRT, non-relocatable
EXE at 0x400000) without touching the game's files. The game runs on macOS in
the CrossOver bottle **X3** (arm64 Wine + FEX, `FEX_X87REDUCEDPRECISION=1`,
`WINEMSYNC=1`); the old bottle **Steam** (x86_64/Rosetta) still exists and is
the default for fixtures. Native Windows is a required target the user cannot
test; every renderer feature must use documented D3D9/Win32 behaviour and fail
closed. Game EXE internals may be hooked (trampolines, IAT hooks, vtable hooks)
with byte validation; disassembly findings are documented under
`docs/reverse-engineering/`, architecture under `docs/architecture/`,
verification under `docs/verification/`.

Install/launch: `python3 tools/manage.py install` (bottle X3 by default),
`python3 tools/manage.py launch --direct ...` (the user launches gameplay; the
agent never does). Every Wine-executing fixture or runner must run as
`python3 verification/probe/wine_lock.py <command...>` (machine-wide lock; one
Wine runner at a time) and refuses while the game is up. Logs land in
`<game>\x3-modern-captures\session-<date>-<pid>.log`; the previous orchestrator
copied each run's log and readbacks to `/tmp/x3-bottleX3-run<N>/` (local
only, never committed; run 7–16 snapshots exist there until reboot).

## 6. Lessons that are not obvious from the code

- Under FEX, a hooked call's x87 state boundary costs ~1.2 µs; that inflated
  the first loading profiles (the "25 s savegame decode stall" was ~17 s of
  instrumentation). Hot hooks now live in no-SSE translation units without a
  boundary (`loading_trace_light.cpp`, `engine_memory.cpp`,
  `resource_reader_core.cpp`, `crypt_cache.cpp`); keep that pattern.
- The in-process sampling profiler cannot attribute samples under FEX
  (`GetThreadContext` returns creation-time context). Use hook counters and
  entry trampolines (`--loading-probes`) on X3; the profiler only on Steam.
- The FEX CRT prints NaN/Inf as huge finite numbers; fixtures print bits.
- The game shadows sampler state and never sets a mip bias itself, but its
  effect files do write bias 0 on cube stages 3/4; the override handles it.
- The save-load stall is dominated by the script signature check re-creating
  a CryptoAPI key container per script (4 ms each), not by file reads.
- GenerateAdjacency parity needed the exact D3DX rules (unstable heapsort
  representative choice, weld refusal, entry lifetime, rsqrtss normal score).
- Exposure for a space game must ignore the black sky and protect highlights.
- `a8d4309` and later WIP commits swept partial agent work into history under
  generic messages; do not rewrite history, just keep reading the reviews.
