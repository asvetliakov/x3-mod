## Decision

**Two steps, no table first.** Step 1 (no file, one rule): the node walk already visits the `fx_engine_emitter` dummies
the M6M family and the Terran drones carry; the drive hides them (`C = 1` lacks `0x1000`) but drives their throttle, so
accepting a hidden JET child whose mode word has no visibility and no steering bits as an **anchor** gives those ships
2–4 plumes at the artist's nozzle positions with the engine's own throttle, sized by the existing floor law `k(R)·R`.
Step 2 (the offline table, capitals only): `x3m/engine_nozzles.json` beside `engine_bodies.json`, one entry per hull
body that has no main glow part, generated by the regenerate tool from the hull's LOD-0 geometry (rear-most slab
centroid, radius from the hull half-width), consulted at the stage append only for a gathered root whose walk found no
jet, throttle from the hull's own motion per game-time step. Rollback at every level: no anchor rule → today; no file
or no entry → today. First flown step: FL, step 1, one M6M.

## 3. Runtime contract

### 3.1 Step 1: emitter anchors (no table)

- **Rule** in `engine_nozzle_walk_core.h`: a child with the JET pair that is `hidden` (`+0x12c & 0x100000`) is today
  dropped. Read its mode word `+0x260` (one 4-byte read, outside the 0x150 block) and keep it as an *anchor* when
  `C & 0x1000 == 0` (never visible) and `C & 0xffe == 0` (no steering, no alternate set) [m: the drive hides exactly
  this case, §2 row `0x0045af0a`; the throttle is still driven toward `base`, i: not re-traced]. A hidden main jet of a
  travel-mode swap has `0x1000` set and stays dropped.
- **Record**: `far_record` as for node records (position `+0xb0`, axis −basis z, `z`/`s` from `+0x88`), `flag_node |
  flag_anchor` (a new bit). **Size**: the emitter body's value is 17 [m, both tables], meaningless; an anchor's size is
  the floor `k(R)·R` with `floor_cap` not applied (the floor curve is already the stage's "size from the ship radius"
  law), so an M6M (R ≈ 320 record units [m: half-length 31646 × 0.01]) gets value ≈ 0.3·R ≈ 95 against a Mayhem
  M6 main jet's 0.16·W ≈ 20–40 [i]. The flight rates it; the knob is the existing `engine_plume_floor`.
- **Dedupe, far jets, culls**: a hidden node never reaches the render pass, the small-parts stub or the frustum test, so
  there is no draw or far copy to dedupe against and no engine verdict (`engine_culls`) to honour; the stage's own px
  rules (1.5 px cull, 2/4 px floors) apply. Identity: the node's handle and `object_lifetime` serial as node records.
- **Transform validity** [i]: the transform walk writes `+0xb0`/basis for every node of the scene before the pass; the
  hidden flag gates rendering, not the walk. Settled by a capture row (below), not by the host.
- **Cost**: +1 read of 4 B per hidden JET child (RCS puffs below `0x28f` are hidden too: ≤ 20 per fighter, ≈ 50 ns each
  [i]); records +2–4 per M6M. No allocation, no new site.

### 3.2 Step 2: the per-hull table (capitals)

- **File**: `<EXE dir>\x3m\engine_nozzles.json`, sibling of `engine_bodies.json`, read once by the same
  `read_table_file` path (`X3M_ENGINE_NOZZLES` override, `0`/`none` disables), parsed by the same JSON cursor into a
  fixed array (capacity 256 hulls × ≤ 4 nozzles, name ≤ 95 bytes). Schema: `{"schema": 1, "edition": "fl", "hulls":
  {"ships\\argon\\argon_TL": {"vmax": 29185, "nozzles": [{"offset": [x, y, z], "radius": r, "axis": [0, 0, -1]}]}}}`,
  offsets and radius in scene units of the hull body frame, `vmax` TShips col 7. Generated by
  `tools/effects/engine_nozzles.py` (sibling of `engine_bodies.py`, same edition detection and mounts) and by
  `x3m-regenerate` step 3 beside the body table, so the file is edition-specific by construction (FL's
  `addon2/types/Bodies` and `addon2/04.cat` TShips [m]); `manage.py install --edition fl` writes `C:\X3FL\x3m\`.
  Baker law v1: hulls whose scene has no main glow part and no emitter dummy; one nozzle at `z = lo_z + 0.05·L`, `x, y`
  = centroid of the LOD-0 points in the rear 5 % slab, `radius = 0.3·W` (p90 of Mayhem's capital value/W [m]); a hand
  entry in the same file wins over the baked one (candidate (c) as the override layer).
- **Key**: the hull body **name**, resolved to a body id by the existing `Resolver` (names → ids over the manager's
  slots, round-robin re-check, load-epoch reset), the same object that keys `engine_bodies.json`; FL's manager at
  `base+0x1aa100` and model at `+0x144` are already handled [m, source]. The ids go into a small open-addressed id set
  (≤ 512 slots). Capacity: the resolver's 1024 entries hold 226–253 bodies today [m]; the hull table adds ≤ 105.
- **Admission**: `engine_node_gather` today admits a root only when it is the own ship or `recent` (a parent of last
  frame's ring records) [m, source], which a no-glow ship never is. Add: admit when the draw's scope `model` is in the
  nozzle id set (one hash probe per scene draw that is not already recent, ≈ 20 ns [i]; ≤ 300 draws → < 6 µs).
- **Append**: in `engine_node_append`, after the root's walk returned `complete` with **zero jets and zero anchors**, and
  the root has no draw/far record this frame (the `Seen` priming already tells), take the first child whose model is in
  the id set (remembered during the single walk: one probe per child, ≤ 108) and build one record per table nozzle:
  `origin = (pos + Σ_k R_k · offset_k · scale_k / 65536) · context_scale`, `axis = R · table axis` (−basis z for
  `[0,0,-1]`), `size = radius · scale70 · scale80 / 65536 · context_scale` [i: the composition mirrors `far_record`'s
  rows, `0x004bdee0`; the host fixture pins it against a reference matrix, a capture pins it against the hull's c4–6],
  `flag_node | flag_table`, identity = the hull node's handle and serial (unique: no jet shares it), parent = root,
  `parent_radius` through the memo, own tag as today. A mod that adds glow parts to a listed hull wins automatically.
- **Throttle** (no node `+0x88`, no object reach [m, §3 of engine-nozzle-source.md]): per gathered root a slot (indexed
  by the root set's slot, 512 × 16 B, generation-stamped) keeps the last origin and game time; `v = |Δorigin| / Δt_game`
  with `Δt_game` the stage's own game-time step (`engine_clock_.last_step × seta_rate_`, the SETA-scaled value the
  travel ramp already uses [m, source]), `s = clamp(v / vmax')` where `vmax'` is `vmax` in record units per game second
  [u: the TShips speed unit against world units; settled by one flight row comparing the own ship's measured `v` with
  the HUD speed, or by the position integrator's disassembly], `z = 0.25 + 1.75·s`. First sight or a jump (`|Δorigin|`
  > 10 ship radii) → idle `s = 0`. Under SETA the step and the displacement grow together, so `s` is unchanged (the
  user's rule); the engine's own 437 game-ms ramp is reproduced by a one-pole filter in game time, not frames.
- **Far jets, small parts, LOD**: no JET node exists, so the far hand-off and the engine's size verdict are not involved;
  the merged-LOD overlay keeps the body name, so the key survives distance LODs [i]. A hull culled whole takes its table
  plume with it, as jets do today.
- **Performance** [i]: per frame ≤ 6 µs of admission probes, the walk cost unchanged (the roots are already walked),
  ≈ 0.3 µs per table record, no allocation after load (fixed arrays), file read once at the first frame as the body
  table. Ring +1–2 records per capital.
- **Native Windows**: Win32 file read as `engine_bodies.json`, no Wine dependency; the regenerate exe already runs on
  Windows and produces the body table there [m, lod-overlay-mods.md].
- **Rollback**: file absent/disabled → no admission, no records, today's behaviour, one `engine_nozzles status=absent`
  row; an entry whose name does not resolve → counted `unresolved`, nothing drawn.

## 5. Options considered and why they lose

- **Table only, no anchors**: leaves the 11/9 M6M-family ships on a synthetic centroid plume when their scenes already
  hold exact nozzle positions and a live throttle; the anchor rule is one read and one guard.
- **Phase-4 site-A stub recorder** (`(obj, k, pos)`, `obj+0x10` speed): gives speed, but only for ships with spawn
  sites (the same 13/11), needs a new per-tick write path and a world transform the proxy computes anyway; the walk
  sees the same nodes for free.
- **Table in a catalogue marker** (`addon2/NN.x3m-lod.json`): the DLL has no catalogue or marker reader and the markers
  are bake provenance; a sibling of `engine_bodies.json` reuses a loader that exists.
- **Section inside `engine_bodies.json`** (schema 2): couples two regeneration steps and two rollbacks; a sibling file
  can be deleted alone.
- **Constant throttle** (`s = 0.5`): parked capitals at every shipyard glow at half power; the motion throttle costs
  16 B per root and one subtraction.
- **Multi-nozzle silhouette analysis in the baker** (pods, bilobed rears): more code for a look the hand override
  already allows; revisit if the flight finds one plume per TL unconvincing.
- **A new hook at the transform walk or pass entry**: untraced liveness for data the proxy already reads.

## 6. Unknown, and what settles it

- `+0xb0`/basis of a **hidden** node are current each frame [i]: a capture row against the hull's rows (flight 1).
- The emitter's `+0x88` is driven while hidden [i, §2 row `0x0045af0a`]: the same flight's `s` varying with speed.
- Scene-unit scaling of LOD-0 points (bob1's inference) and the composition of offset → world [i]: host fixture
  against `far_record`'s rows, then the TL capture.
- TShips speed unit vs world units per game second [u]: one own-ship row (HUD speed vs measured `v`), or the
  integrator's disassembly (`obj+0x10` into the position).
- Hull node per-axis scales `+0x80/84/88` are unit [i]: the walk's guard would reject otherwise (counted).

### As built (step 1, 2026-11-03, not flown)

**Both editions at runtime since the FL walk activation (2026-11-03, not flown).** The rule rides on the node walk,
which FL honours since [fl-nozzle-walk-activation.md](fl-nozzle-walk-activation.md) ("As built": owned context scale,
the append at the hook's scene end only). The FL build runs the rule with FL's model offset `+0x144`
(`engine_node_layout.h`, now set for every walk, anchors or not); the native fixture's `node_walk` section
(`verification/probe/fl_cull_chain.cpp`) walks hidden emitters on the FL layout with decoys at AP's offset, and
`engine_plume_emitters = 0` reads no C word and admits no probe there. On AP only stock content has anchored hulls:
Mayhem 3 has none [m, `anchor_census_out.txt`]. The FL flights: run 32 with `engine_plume_emitters = 0` (the walk
alone), run 33 without that line (the anchors). The hull rows (`engine_plumes_hidden_emitter_hull`) are now written
after the root loop, so no file write sits between two list reads.

- **Who** [m, [`anchor_census.py`](../../verification/results/plumes-no-glow/anchor_census.py) →
  `anchor_census_out.txt`]: FL 16 ships / 35 emitters, stock AP 14 / 29, Mayhem 0. More than the 11 / 13 above
  because the drones (`SS_SH_FIGHTDRONE`, `_RECONDRONE`, `_A_MK2DRONE`) carry one `C = 1` emitter and no glow part.
  The M6M family's emitters carry **`C = 0`**, not 1 (both count as main: the drive's `C & 1 || C == 0`). 181 FL / 172
  stock / 494 Mayhem ships carry emitters **beside** glow parts; the rule leaves them unchanged.
- **Rule** (`engine_nozzle_walk_core.h`, `Options::anchors`): per hidden JET child, until the root shows a glow part,
  one 4-byte read of C at `+0x260`. A child with `C & 0x1000` is glow (a hidden travel-swap set). A shown child counts
  as glow unless its body is a steering body (`v/00566` or a SMALLJET entry), so a shown RCS puff does not cancel the
  anchors and a shown brake jet does. Anchors are children with `C & 0x1ffe == 0`, the emitter body identity (the
  model resolves to the `effects\engines\fx_engine_emitter` table entry, so the drones' hidden `C = 0`
  `fx_engine_terran_transportdrone` glow body is refused), unit x/y scales, and `+0x88` in `0x4000..0x20000`. That
  driven-throttle guard is the **ship-only gate**: placement sets every object's JET children to `(1, 1, 0x28f)` and
  hides them, with no class test (AP `0x451cd5`, FL `0x45b830`). Only class 7 reaches the jet drive through the sector
  update's class switch (AP `0x45b634/0x45b64c`, FL `0x464fa8/0x464fc0`). A station's, missile's or debris' hidden
  emitter therefore stays at `0x28f` and never anchors, so the uncapped `k(R)·R` is only ever applied to ships
  [m, fixture `non_ship`]. The walk has no object pointer, so the class word `obj+0x48` itself is not read. Anchors are handed out only after the list's end
  of a **complete** walk, and only when no glow part was seen. Without the option the walk is the one before step 1,
  read for read (the old two-argument `walk()`).
- **Record** (`anchor_record`): the emitter's `far_record` (origin `+0xb0` × context scale, axis −basis z, `z`/`s`
  from its own `+0x88`), then size = `k(R)·R` from `floor_ratio_at` at the ship radius in record units, with no
  `floor_cap`. `engine_plume_floor = 0` therefore means no anchor (`no_floor`). Body −1 in the **cyan** cluster (the
  stock engine family: the emitter entry's black material would read white), `flag_node | flag_anchor` (bit 11), the
  node's lifetime serial as node records. At the default floor 0.5 an M6M (R = 320) gets size 45.9 [m, fixture], about
  half the 95 estimated above (that estimate used floor 1).
- **Admission**: the gather's ship filter is unchanged for recent roots. A root no record named in two frames gets
  one `AnchorProbes::due` probe per routed scene draw (0.9 ns on the host [m]). It is admitted for an
  **anchors-only** walk when it has no entry, its last walk **anchored**, or its last walk is ≥ 2,000 game ms old (the
  stage step × the SETA rate; 100 frames at 20 ms, 10 frames under SETA ×10 [m]) or ≥ 600 frames old. At most 4 new
  probe roots per frame (`probe_deferred` counts the rest). An anchored root is due at once, so a frame without its
  anchor records (hull not drawn, ring full, no camera scale, a view switch) costs its plume at most until the next
  draw, not 2 s (fixture: skipped at 11, re-walked at 13 [m]). A probe walk never emits a jet and never enters the
  light's walked set, so stations, asteroids and glow ships seen through a probe keep today's records and hold. Their
  lists **are** now read, once per 2 game seconds each, which revises review S1's "no list of theirs is read". An
  anchored root's records mark it recent, so from the next frame it takes the ordinary full walk. The table holds
  probe walks and anchored (or anchor-less) roots only, never a recent glow ship, so writes per frame are ≤ 4 + the
  anchored hulls in view, and a fleet of glow ships cannot evict the stations' entries. A load clears it.
- **Light and trail**: anchor records are node records in the ring, so the engine light (`engine_light_core.h`
  ship table) lights the hull plates around them and the ribbons (`engine_ribbons_core.h`) draw a trail behind them,
  as for any plume. Natively these ships had an `EEDF_LIGHT` row 5 hull light only.
- **Cost** [m, host fixture, scattered 108-part roots, one run]: 1.19 µs per root before, 1.19 with the rule on (4
  shown jets, one predicate each), 1.18 for an anchors-only probe walk; probe 0.9 ns per draw. Probe walks add to
  `node_children`, `node_hidden` and `node_guard_rejected` in `engine_stage` (Mayhem included) with no record change. The production reader's per-read cost applies to the
  extra C reads, one per hidden JET child before the first shown glow part. No allocation; 12 KB probe table, 576 B of
  stack per walk.
- **Rows**: `engine_plumes_hidden_emitters … event=configure setting= status= rule= reason= edition=` once per
  configure; `… event=body rule= emitter_body= bodies=` once the body table is loaded; `… event=window rule=
  edition= emitter_body= anchors= ships= frames= anchored_frames= probes= probe_deferred= glow= not_emitter=
  rejected= no_floor= mode_reads= new_hulls= hull_rows_dropped= walk_us_max=` per 300 frames;
  `engine_plumes_hidden_emitter_hull … root= first_handle= anchors= candidates= not_emitter= rejected= probed= own=
  radius= size= s= scale=` once per newly anchored hull, at most 32 per configure. `engine_stage` (`--debug`) gains
  `node_anchors= node_anchor_roots= node_probes=`.
- **Probe diagnostics** (FL run 34 build, 2026-11-03; telemetry only). The window row gains, after
  `hull_rows_dropped=`, the probe walks' own subtotals: `probe_walks=` (anchors-only walks of probe-admitted roots;
  `probes=` counts admissions at the gather, and an admitted root without a context scale is not walked),

  emitters; `rejected` an emitter candidate or a handed anchor yielded no record (guard, capacity, unreadable C, no
  floor size); `none` otherwise (a station, an asteroid, a hull whose hidden children are other bodies).
- **Rollback**: `engine_plume_emitters = 0` (`X3M_ENGINE_PLUME_EMITTERS`, builtin 1) leaves the walk and the gather
  as before; so does `engine_nozzle_source = draw`.
- **Section 6, settled for step 1** [m, [`hidden_emitter_reads.py`](../../verification/results/plumes-no-glow/hidden_emitter_reads.py)
  → `hidden_emitter_reads_out.txt`, 24 PASS on the documented EXE hashes]. Hidden-node transform currency: the
